# Granola-Notes

Automatically-synced archive of class lecture notes from Granola. Each class gets its own folder under `classes/`, and a new note is added there whenever a class is recorded and captured in Granola.

**Browse the notes:** https://emilyvanasse.github.io/Granola-Notes/ — a small site built from this repo's markdown and redeployed automatically after every daily sync (see `scripts/build_site.py` and `.github/workflows/pages.yml`).

See `CLAUDE.md` for how the sync works.
