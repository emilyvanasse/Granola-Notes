## Summary

### Equation of Exchange Recap

- Equation of exchange: M × V = P × Y
- In growth rates: GM + GV = inflation + GY (left side = nominal spending = aggregate demand)
- AD curve: downward sloping, inflation on Y axis, GY on X axis
  - Movements along: changes in inflation or GY
  - Shifts: changes in GM or GV (via consumption, investment, govt spending, net exports)
- Long run aggregate supply (LRAS): vertical at potential output
  - Location determined by resources, institutions, technology
  - Unemployment = natural rate at potential output

### Short Run vs. Long Run: Sticky Prices

- Defining feature of the short run: sticky prices
- Long run assumption: prices are perfectly flexible, fully absorbing demand changes
- Sticky price examples:
  - Wages: fixed by salary contracts, typically for \~1 year
  - Rent: personal leases (12 months), commercial leases (3-5 years)
  - Mortgages: 30-year fixed rate in the US
  - Input contracts: coffee shop locking in milk, cups, beans at fixed prices
- Flexible price examples: gas, chalkboard-menu coffee shops (outputs easy to reprice)
- Key asymmetry: input costs often fixed by contract, output prices can still move

### Short Run Aggregate Supply (SRAS) Curve

- Shape: positive slope, getting steeper to the right, flatter to the left (hyperbolic)
- Why steeper to the right:
  - As output rises above potential, resources become increasingly scarce
  - Hiring, sourcing inputs gets harder; eventually hits a hard physical limit
- Why flatter to the left:
  - Wages are downward rigid: firms fire workers rather than cut nominal wages
  - Small price drops cause large output losses
- Location: SRAS intersects LRAS at expected inflation
  - Change in actual inflation: movement along SRAS
  - Change in expected inflation: shifts SRAS up or down

### Long Run Equilibrium and the Full Model

- Long run equilibrium: all three curves (AD, LRAS, SRAS) intersect at one point
- Example setup: GM = 5%, GV = 0%, expected inflation = 2%, GY = 3%
  - Derived: 5% = 2% + 3%, confirmed at equilibrium
  - Unemployment = natural rate

### Demand Shocks: Short Run and Long Run Effects

- **Fed increases GM (e.g., 5% → 10%)**

  - AD shifts right (A → B, short run equilibrium)
  - Short run: inflation up, output up, unemployment below natural rate
  - Sticky wages/rent prevent full price adjustment, so output rises temporarily
  - Long run: workers demand raises, landlords raise rents, contracts renegotiate
  - Inflation expectations update upward; SRAS shifts up (B → C)
  - Long run equilibrium: output and unemployment return to potential, inflation permanently higher

- **Fed decreases GM (e.g., 5% → 1%)**

  - AD shifts left; new equilibrium at lower inflation and lower GY
  - Short run: inflation down, output down, unemployment above natural rate
  - Downward wage rigidity means firms fire workers rather than cut wages, amplifying output drop
  - Long run: inflation expectations fall; SRAS shifts down
  - Final equilibrium: output and unemployment restored, inflation = -2% (in this example)
  - Key implication: reducing high inflation historically requires a recession
