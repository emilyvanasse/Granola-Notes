## Summary

### Exercise 23: Farnsworth Dry Cleaning (Fixed vs. Variable Costs)

- Variable cost per unit: $0.70 ($4,200 ÷ 6,000 garments), constant across all production levels
- Fixed cost total: $14,400 (6,000 × $2.40), same at all three production levels
- Total operating costs by volume:
  - 4,500 garments: $17,550
  - 6,000 garments: $18,600
  - 7,500 garments: $19,650
- Fixed cost per unit decreases as production increases
  - 4,500 units: $3.20, 6,000 units: $2.40, 7,500 units: $1.92
- Req. 3 (danger of using average cost): using $2.62/unit (full capacity average) for 4,500 units predicts $11,790, vs. actual $17,550
  - Underestimates by $5,760; illustrates why average cost should never be used to predict total cost

### Exercise 25 \&amp; 26: Cost Equation vs. Average Cost

- Robert’s Mailbox (Ex. 25): average cost $23.43 for 1,400 mailboxes, total cost $32,802
  - Fixed costs: $20,202; variable costs: $12,600; variable cost per unit: $9
  - Cost equation: Y = $9x + $20,202
  - For 1,500 mailboxes: average cost predicts $35,145; cost equation gives $33,702
  - Difference of $1,443; average cost overstates, leading to inflated selling price
- Carrollton Buffet (Ex. 26): $30/person buffet, $143,000 fixed costs, $15/guest variable cost
  - Cost equation (≤14,000 guests): Y = 15x + $143,000
  - At 13,000 guests: total cost $338,000, average cost $26/guest
  - At 11,000 guests: correct total $308,000; manager using average cost incorrectly forecast $286,000
  - Above 14,000 guests: fixed costs rise by $22,000 (additional servers); new equation Y = 15x + $165,000
  - At 15,000 guests: total cost $390,000

### Exercise 37: High-Low Method (Somerville Company)

- High month: June, 1,480 machine hours, cost $4,192
- Low month: March, 1,080 machine hours, cost $3,532
- Variable cost per machine hour: $660 ÷ 400 = **$1.65**
- Fixed cost: $4,192 − ($1.65 × 1,480) = $4,192 − $2,442 = **$1,750**
  - Can double-check by computing at the low point; result should match
- High-low formula will be provided on the exam; plug in numbers to solve

### Exercise 38: Absorption vs. Variable Costing (Royal Industries)

- Key data: selling price $49, DM $18, DL $6, total overhead $221,000 ($187,000 fixed), variable operating cost $3/unit, fixed operating expense $47,000
  - Produced 17,000 units, sold 13,000 units → 4,000 units in ending inventory
- Product cost per unit:
  - Absorption: $18 + $6 + ($221,000 ÷ 17,000) = $37/unit
  - Variable: $18 + $6 + ($34,000 ÷ 17,000) = $26/unit (variable overhead only)
- Ending inventory: absorption $148,000 (4,000 × $37), variable $104,000 (4,000 × $26)
- COGS: absorption $481,000 (13,000 × $37), variable $338,000 (13,000 × $26)
- Operating income: absorption $70,000, variable costing $26,000
  - Difference driven by fixed overhead in inventory under absorption
- Exam format notes:
  - Must draw the full income statement from scratch
  - Absorption: Sales → COGS → Gross Profit → Operating Expenses → Operating Income
  - Variable: Sales → Variable Costs → Contribution Margin → Fixed Costs → Operating Income
  - Format correctness prioritized over perfect numbers; always show all work, even on calculation-based multiple choice (partial credit possible)
  - Cost and high-low formulas provided on exam; memorize the format, not the formulas
