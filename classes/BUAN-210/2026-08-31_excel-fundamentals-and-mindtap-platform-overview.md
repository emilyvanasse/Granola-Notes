# Excel Introduction and Key Concepts

- Excel described as an extraordinarily complex tool (estimated 15,000-25,000 person-years to build)
  - Capabilities: formulas, charts, pivot tables, Power Pivot, data connections, VBA
- Key navigation covered:
  - Ctrl+Right/Down Arrow to jump across rows/columns; Ctrl+Up to return
  - Home key returns to column A from anywhere in a row
  - Name Box for direct cell navigation (e.g., type "AA1")
  - ~1 million rows available
- Ribbon is dynamic: collapses and changes layout at smaller window sizes
  - File tab opens Backstage View (cannot be collapsed)
- Worksheet vs. workbook distinction: workbook contains multiple worksheets (tabs)
  - Rename tabs by double-clicking; Ctrl+Page Up/Down to navigate between sheets
- Numbers align right by default; text aligns left; pound signs (###) mean column too narrow
- Basic income statement built live: Sales, Cost of Sales, Gross Profit formula (=C4-C5)
- Formatting shortcuts: Ctrl+B (bold), Ctrl+I (italic), Ctrl+U (underline); alignment under Home tab
